# 02편 영상 진행상황 (2026-11-06)

## 방식
- 컷마다 '시작 이미지'(키프레임 + 언니를 일하는 자리에 넣은 이미지, 0크레딧)를 먼저 만들고 → Flow 프레임 모드(시작 이미지 1장, 720p, 4초, 7크레딧)로 영상 생성
- 앞 컷 마지막 장면에서 바로 이어 만들면 언니가 카메라 앞에 있어 카메라가 따라 움직임 → 탈락 원인이라 이 방식으로 바꿈
- 검수: 영상의 중간·마지막 장면을 '프레임 저장'으로 원본 크기 받아 확인(저절로 생기기·사라지기, 카메라 움직임, 되돌아가기 체크)
- 시작 이미지: `키프레임\시작이미지\`, 검수 프레임: `영상\검수프레임\`

- 15 넓게: 수납장·타일 닦기 / 16 줌인: 싱크 옆 타일 닦기 / 18 줌인: 스퀴지 한 줄씩 투명

- 주의: 동시 생성 한도(약 3개)를 넘기면 생성이 조용히 안 걸림 → 3개씩 걸기

## 중단 (11/6) — Flow '비정상적인 활동 감지'
- 벽지 뜯기 시작 이미지 생성 때 Flow가 "비정상적인 활동이 감지되었습니다(페이지를 수정하는 브라우저 확장 프로그램)"로 실패 처리
- 자동 입력이 봇 탐지에 걸린 것으로 보임 → 우회 시도하지 않고 멈춤

## 재개 (11/6 저녁) — 일반 클릭·타이핑으로만 진행, 비정상 활동 감지 다시 안 뜸
